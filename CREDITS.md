# Credits — Last Train Home, Day 1 prototype

## Art
All map, building, prop, vehicle and character art in the delivery minigame is **original code-drawn vector art**
(HTML canvas, `town.js`), made for this project. No third-party tilesets, sprites or AI-generated images are used.
- Town layout: hand-laid tile map `data/minase_map.js` (generated once by `tools/make_map.py`, then editable as ASCII).
- Shop signs and a few HUD icons use the device's built-in **emoji font** (Apple / Google / Microsoft system emoji),
  rendered at runtime, not bundled.

## Code
Original. No external libraries.

## Fonts
System UI font of the device (`system-ui`). Nothing bundled.
